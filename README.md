# Dashboard Template

A responsive Dashboard template built using HTML and CSS.

## Preview

A multi-page admin dashboard with various widgets and data visualization sections

- **Dashboard (Main):** Overview of statistics, quick actions, and tasks.
- **Courses:** Track and display available or enrolled courses.
- **Friends:** A clean layout showcasing user connections or team members.
- **Profile:** Comprehensive user profile page with personal details.
- **Plans:** Pricing or subscription plans layout.
- **Projects:** Management board for tracking ongoing projects.
- **Settings:** Control panel for user preferences and system settings.

## Technologies Used

- HTML5
- CSS3
- Font Awesome (for icons)
- Google Fonts

## Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- **Custom CSS Framework:** Built using a dedicated `framework.css` file for reusable utility classes (Flexbox, Grid, padding, margins, colors).
- **Clean UI & Modern Layout:** Minimalist design with smooth shadows and explicit spacing.
- **Highly Modular:** Clean HTML structure with clear descriptive comments for each widget.
